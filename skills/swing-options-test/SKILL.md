# اختبار فرضيات الأيام والأسابيع

1. **اكتب الفرضية أولًا** في `docs/hypotheses/` قبل أي تشغيل: الإشارة، والعقد، والخروج، والتكاليف، والفترتان، ومعيار القبول. لا تُعدَّل بعد رؤية النتائج.
2. **اجلب البيانات اليومية** (يحتاج `yfinance`):
   ```bash
   python3 skills/swing-options-test/swing_test.py fetch --out data/swing
   ```
3. **شغّل:**
   ```bash
   python3 skills/swing-options-test/swing_test.py run --data data/swing --out reports/swing
   ```
   - `trades.csv`: كل صفقة. فيها `r_underlying`، نتيجة الأصل نفسه بوحدة ATR، وتفصل ضعف الإشارة عن غلاء العقد.
   - `verdict.json`: الحكم بمعيار القبول.
4. **اعرض النتيجة بالعربية** مع درجة اليقين، واكتبها في ملف نتائج الفرضية.

**حدود:** التسعير بنموذج بلاك–شولز بتذبذب VIX أو VXN، لا بأسعار OPRA، ويغفل ميل التذبذب. الحكم «مقبولة» يفتح التجربة الورقية فقط، ولا مال حقيقي قبل التسعير بعقود فعلية.
