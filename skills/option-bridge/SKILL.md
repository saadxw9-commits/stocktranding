# جسر الإشارة إلى العقد

## المسار

1. `stock-analyst` يبني الآراء من حزم Jake وtradermonty والعدسات.
2. `verification-layer` يصدر الحكم والمستويات المتحفظة.
3. **هذا الجسر.**
4. `option-selector` يقارن العقود لكل تاريخ انتهاء.
5. يُرشَّح أفضل عقد.

لا يعمل الجسر إلا بحكم «صالح للعرض»، أو «اقتراح معلّق»، والثاني يخرج قراره `PENDING_OWNER` للمراجعة. أي حكم آخر يوقف المسار.

## الخطوات

```bash
# ١) الخطة من تقرير التحقق
python skills/option-bridge/bridge.py plan reports/verification/verify-<السهم>-<اليوم>.json --out reports/options/plan-<السهم>.json

# ٢) اجمع سلسلة العقود لتواريخ الانتهاء داخل نافذة الخطة (انظر fixtures/chain-TSLA-synthetic.json)
# ٣) الاختيار
python skills/option-bridge/bridge.py select reports/options/plan-<السهم>.json chain.json --cash <النقد المتاح> --budget <ميزانية الصفقة> [--mode cheap --signal signal.json]
```

**الخطة تحدد:**
- **الاتجاه:** شراء (`long`) يعني Call، وبيع (`short`) يعني Put. الـPut هنا شراء بخسارة محدودة بالعلاوة، لا بيع مكشوف للسهم.
- **المستويات:** الدخول والإلغاء والهدف تؤخذ من `conservative_levels` في تقرير التحقق.
- **وقت الخروج:** وقت الرأي مضافًا إليه `horizon_days` من أيام التداول، عند الساعة 15:30 بتوقيت نيويورك. العطل الرسمية لا تُحسب، فتحقق من التقويم.
- **نافذة تواريخ الانتهاء:** أقل عدد أيام متبقية هو الأكبر بين `min_dte` وضعف مدة الاحتفاظ بالأيام التقويمية. تمتد النافذة بعده `window_days` يومًا. القيم في `swing_expiry` داخل `config/options-universe.yaml`.

**عند الاختيار تُفحص حالة السعر أولًا:**
- `wait_for_entry`: السعر لم يصل نقطة الدخول.
- `invalidated`: السعر تجاوز مستوى الإلغاء.
- `target_already_reached`: السعر وصل الهدف قبل الدخول.

ثم يُشغَّل `option-selector` على كل تاريخ انتهاء داخل النافذة بوقت الخروج نفسه، فتمر كل العقود على البوابات نفسها: المدة، والتسوية، وإعلان النتائج، والتذبذب، والسيولة، والحساسية، والسيناريو. ويُختار أعلى ربح عند الهدف.

## العرض

- **العقد المختار:** الأصل وتاريخ الانتهاء وسعر التنفيذ وسعر الشراء، وأقصى خسارة، والحساسية، والفارق بين العرض والطلب.
- **السيناريوهات:** الربح أو الخسارة عند الهدف وعند الثبات وعند الإلغاء. كلها تقديرية بتذبذب ثابت.
- **وقت الإغلاق الإلزامي** إن وُجد.
- **سبب استبعاد كل تاريخ انتهاء آخر.**
- **حدود الحساب:** المحاكاة ورقية. الحساب يعدّ الوصول إلى الهدف أو الإلغاء حاصلًا عند وقت الخروج، وهذا متحفظ في الحالتين.

القرار النهائي للمالك.
