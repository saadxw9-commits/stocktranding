# طبقة التحقق

لا يُعرض أي اقتراح دخول على المالك قبل أن يمر من هنا.

## الخطوات

1. اجمع لكل سهم مرشح:
   - رأي **الأساسي** من مخرجات حزمتي Jake (ملفات `trader/` داخل `workspaces/swing` أو `workspaces/day`).
   - رأي **الرديف** من مهارات tradermonty المقابلة للدور (انظر جدول الأدوار في `CLAUDE.md`).
   - رأي عدستين أو ثلاث من investorskills حسب `config/lenses.yaml` (`default_per_analysis`)، وعدسة التحذير دائمًا.
2. حوّل كل رأي إلى صيغة `schemas/opinion.schema.json`، ولا تخترع مستوى لم يذكره المصدر: اتركه `null`.
3. احفظ الآراء في ملف واحد وشغّل:

```bash
python3 skills/verification-layer/compare.py <ملف_الآراء.json> --out reports/verification/
```

4. سجّل الآراء والحكم في السجل:

```bash
python3 skills/journal/journal.py add-opinions <ملف_الآراء.json>
python3 skills/journal/journal.py add-verification reports/verification/<الملف>.json
```

5. اعرض التقرير العربي كما خرج، ثم أضف تفسيرك للتفاوت في فقرة منفصلة معنونة «تفسير» مع درجة اليقين.

## معنى التصنيفات

| البعد | القيم | المعنى |
|---|---|---|
| الحجم | صغير / متوسط / كبير | أكبر فرق في المستويات أو الثقة، حسب `config/verification.yaml` |
| النوع | إيجابي / سلبي / محايد | هل الرأي الآخر أكثر تفاؤلًا من الأساسي أم أكثر تحفظًا |
| المنطقية | منطقي / غير منطقي / غير محسوم | هل يفسر الفرق اختلاف الأفق أو المنهج، أم لا تفسير له، أم الأدلة ناقصة |
| الخطورة | مقبول / يحتاج مراجعة / خطير | خطير: اتجاهان متعاكسان، أو خطأ منطقي في المستويات، أو عدسة تحذير تقول تجنّب |

## الأحكام

- **صالح للعرض:** يُعرض مع المستويات المتحفظة.
- **اقتراح معلّق:** يُعرض كملاحظة تحتاج قرار المالك، لا كاقتراح.
- **تعارض:** يُعرض التعارض وأسبابه فقط.
- **دون حد الثقة / دون حد العائد:** يُسجَّل ولا يُعرض إلا إذا طلبه المالك.

لا تعدّل الحكم يدويًا. إذا رأيت أن الحكم خاطئ فاكتب ذلك في «تفسير» واقترح تعديل العتبة في الإعدادات.
